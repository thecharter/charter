# Tolerated differences from eFLINT

The complete list of ways Charter's outcome on a corpus file may differ from
eFLINT 4.1.0.1's, each under the decision that names the eFLINT defect and the
fix (D2). A difference not listed here is a Charter bug. `charter test --expect
eflint-outcomes.txt --tolerate tolerances.md` reads every path in backticks in
this file: a listed file must *differ* from eFLINT's recorded outcome (the runner
fails if it agrees, so a tolerance that is no longer needed is deleted), and an
unlisted file must agree. Paths in this file are therefore only written in
backticks when they are tolerated.
