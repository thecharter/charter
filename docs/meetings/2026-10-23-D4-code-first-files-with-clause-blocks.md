# D4 — A `.charter` file is code that quotes its English in `Clause` blocks; a literate `.charter.md` container comes later and lowers to the same `Doc`

**Laws:** 8, 12, 13 (docs/mission.md). Brief: B1 in `2026-10-22-briefs-for-ruling.md`.
**Date:** 2026-10-23
**Status:** ruled (Eric), as predicted

## Ruling
Code-first `.charter` with `Clause` blocks checked verbatim against `Document "path"`, in Phase 1. In Phase 5, a `.charter.md` literate form whose fenced blocks are extracted and whose clause ids derive from headings (Catala's convention), lowering to the identical `Doc`. The literate form is a container, not a second grammar, so Law 13 holds. Goal 3's "reads as the agreement people sign" is the `charter render` projection.

## Reopens if
PSA authors find `Clause` blocks unreadable beside the Markdown, or `render` cannot reproduce the signed document faithfully.
