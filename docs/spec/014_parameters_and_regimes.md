# 014 — Parameters and regimes

**Status:** approved (Eric, 2026-11-06; Charter 1.0.0). Fixed by D7, D11, D24, and D25. Implementation: compliant (`src/Charter/Core/Amend.lean`, `src/Charter/Eval/Step.lean`).

**14.1 Parameters are facts (D11, D24).** `Param name [: Int | Time | Duration | Money(CUR, SCALE) | Quantity(UNIT)] = n` declares a `Var` fact over the named domain (`Int` by default) whose initial instance is `n`. Any position of that type may name it as a variable (`notice-window + 1`), binding to the instance that holds. An act may `Creates name(m)`; the `Var` restriction makes the new instance the only one, and the program judges that amendment like any event: it occurs, it is lawful or not, it is valid or not. `test/spec/spec_014_1_param.eflint`, `spec_014_1b_param_typed.eflint`, `spec_014_1c_param_as_duration.eflint` (a `Duration` parameter as the `For d` of `Creates e For d`)

**14.2 A parameter is a declaration.** It is introduced with the declaration block it appears in (011.6); its initial instance is assigned by that block, with the origin *asserted* (004.10).

**14.3 Rule amendment (`D11`, `D25`, `G3.5`).** `Amend name [Actor v] … [Repeals r₁, …] [Installs { decls }] Valid when c …` declares an institutional amendment act (`CHR032` if `Valid when` is omitted). Performing an `Amend` is an event in the trace: if valid, it advances `lawVersion` (`v -> v + 1`), repeals/installs the target rule records in `Spec`, recomputes strata, and leaves already-accrued non-derived facts and duties in `State` intact with their original timestamps (`T23`); if void, it occurs with `valid: no` and leaves `Spec` and `State` unchanged. `Extend` remains declaration-time only. An `Installs` block declares rules, not state: a `Param` inside it is CHR037, and an amendment changes a parameter with `Creates name(v)` (14.1). `test/spec/spec_014_3_amend_non_retroactive_escrow.charter`, `spec_014_3c_amend_cannot_install_param.charter`

**14.4 Regimes (`D11`, `D25`, `G3.5`).** `Regime name { p₁ = n₁, p₂ = n₂ }` declares a named initial-state parameter overlay over declared `Param`s, selectable via `--regime <name>` on `charter explore` and `charter verify`. `test/spec/spec_014_4_regime_overlay.charter`

**14.5 Reflexive entrenchment and universal ratchet (`D11`, `D25`, `G3.5`).** `Immunity I Holder v Against Amend [Protects r₁, …] [Holds when …] [Unless …]` (or naming specific `Amend` acts in `Against`) reflexively protects `Protects` targets, all `Entrenched Invariant`s, `I` itself, and every type/rule read in `I`'s conditions or `Amend`'s `Valid when` (`reflexiveProtectedIds`). Any `Amend` touching a protected rule while an un-lifted instance of `I` holds is void (`T24`; proved over arbitrary valid trajectories by `Charter.Amend.cir_ratchet_trajectory_preserves_entrenched`). `Amend Procedure [Actor v] Valid when c` declares a default competence rule inherited by any `Amend` that omits `Valid when`, and `Immunity I … Against Amend Protects Clause c₁, …` entrenches every rule and parameter grounded in those clauses (`D35`, `#54`). `test/spec/spec_014_3b_amend_reflexive_ratchet.charter`, `spec_014_5_amend_procedure_and_clause_protects.charter`
